# wxpub — 公众号发文

`wxpub` 把 markdown 文章投到指定公众号的**草稿箱**（不群发；群发永远由用户在公众号后台人工完成）。渲染、主题、调性、AI 生图都在服务端，CLI 只做投递。

前置：`wxpub me` 检查登录态；未登录 → 让用户自己跑 `wxpub login`（设备流，浏览器批准）或提供 API Key。

## 快速决策（要做什么 → 跑哪条）

| 场景                       | 命令                                                  |
| -------------------------- | ----------------------------------------------------- |
| 给公众号写文章（先拉调性） | `wxpub --json tone -a <账号>`                         |
| 投递文章到草稿箱           | `wxpub --json publish -a <账号> -f <md文件>`          |
| 给文章生成配图             | `wxpub --json illustrate -a <账号> -f <md文件>`       |
| 上传本地图片做插图         | `wxpub --json image -a <账号> -f <图片>`              |
| 查账号默认主题 / 素材      | `wxpub theme -a <账号>` / `wxpub materials -a <账号>` |

账号 key：`danxin`（码骨丹心，后端技术）/ `mingdeng`（明灯，生活指南）/ `ailang`（AI浪，科技解读）。

## 标准工作流（写文全链路）

1. `wxpub --json tone -a <账号>` —— 取 persona（主笔人设）+ style_rules（结构规则）+ 字数区间，**注入写作上下文后再动笔**；`tone:null` 表示该号未绑定，按用户口述要求写
2. 按调性写 markdown，存成文件（标题写进首个 `# 一级标题`，publish 会自动取）
3. 需要插图时 `wxpub --json illustrate -a <账号> -f 文章.md`，把返回的 `markdown` 字段（`![配图](mmbiz url)`）插到正文合适位置
4. `wxpub --json publish -a <账号> -f 文章.md` 投递，取 `media_id` 复命，并提醒用户：**已入草稿箱，群发请到公众号后台人工确认**

## ⚠️ 铁律（必守）

1. **写文前先拉调性**——要动笔写（而非原样转发现成稿）就必须先 `tone`，除非用户明说"不用管调性"。调性就是该号的人设，跳过=成稿风格不符。
2. **别改主题**：publish 永远不传 theme，账号在服务端配置的默认主题（丹心红/明灯绿/AI浪蓝）自动生效。
3. **illustrate 是同步长任务**（10-60 秒出图+上传），命令退出即完成——不要轮询、不要并行跑多个、失败读 message 决定是否换 prompt 重试一次。
4. **重复投递返回 `duplicate:true` 不是失败**——内容没变被幂等去重，草稿箱还是原来那篇。要强制新建草稿才加 `--force`（须用户明确要求）。
5. **成功判据看 `media_id`**：`{"ok":true,"media_id":"..."}` 才算投递成功；`ok:false` 或报错时把错误信息原样呈现给用户，不要自行猜测重试。
6. **只落草稿箱，绝不群发**——发完必须告知用户"请到公众号后台确认群发"，不能宣称"已发布"。
7. 写长文（>2000 字）时给 digest（分享摘要，≤54 字）；笔名用 `--author` 仅在用户明确指定时传。

## 回执判读（--json 输出）

| 命令       | 字段                                         | 含义                                         |
| ---------- | -------------------------------------------- | -------------------------------------------- |
| publish    | `ok` / `media_id` / `duplicate`              | 成功 / 草稿素材 id（复命凭证）/ 是否幂等去重 |
| tone       | `tone` / `tone.persona` / `tone.style_rules` | null=未绑定 / 人设 / 结构规则                |
| illustrate | `url` / `markdown` / `media_id`              | mmbiz 图址 / 现成插图片段 / 素材 id          |
| image      | `media_id` / `url`                           | 永久素材 id / 内嵌用图址                     |

失败输出形如 `✗ 服务端返回 <code>：<人话原因>`——照原因行动（401=让用户重新 login；429=配额，明日恢复；5xx=稍后再试）。
